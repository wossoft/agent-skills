# 任务

## 目标与背景

要达成的结果，以及实现所需的最少背景。

## 范围与约定

允许修改的文件或模块、相关接口与契约、明确排除的内容。

## 规则与限制

- 适用的仓库规则和用户约束（worker 不一定会自动加载，重要的写在这里）。
- 与本任务相关的已有改动或上下文（worktree 基于 HEAD，看不到未提交改动）。
- 额外授权（默认不提交、不推送、不发布、不删数据、不改全局配置）。

## 验收标准

主 agent 可以核验的可观察结果。

## 验证

需要执行的检查命令及预期结果；明确不执行或无法执行的检查。

## 修订上下文（仅修订时）

上次运行目录、上次的验收意见，以及需要修复的问题清单。
